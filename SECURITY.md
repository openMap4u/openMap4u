# Security Policy

## Supported Versions

The following versions of the project are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please report vulnerabilities by opening an issue on our [issue tracker](https://github.com/openMap4u/openMap4u/issues).
